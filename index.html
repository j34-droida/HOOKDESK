⚙ 프록시 서버 설정 (팀 전체 공용, 1회만 설정)

개별 로그인 없이 팀원 전체가 회사 API 크레딧으로 생성하려면, Cloudflare Worker 주소와 팀 코드를 입력하세요. 비워두면 이 화면을 Claude.ai 아티팩트로 열었을 때만 작동합니다.

1. 트랙 선택

트랙 A국내거주 외국인 에이전트 모집
트랙 B해외 인플루언서·연예인 섭외
트랙 C병원·식당·헤어메이크업 광고주 모집

2. 세부 정보

AI가 해당 언어로 직접 작성해 번역기보다 자연스럽지만, 최신 업계 슬랭까지는 완벽하지 않을 수 있어요. 게시 전 원어민 검수를 권장합니다.
내용 추가·삭제 지시("~은 빼줘", "~를 더 강조해줘")나 디자인 지시("어두운 톤으로", "숫자를 크게")를 자유롭게 적을 수 있어요.

3. 레퍼런스 링크 (선택)

참고할 페이지나 자료 링크를 붙여넣으면 톤 참고용으로 함께 저장됩니다.

4. 이미지 첨부 (선택)

드래그해서 놓거나, 이미지를 복사해서 붙여넣기(Ctrl+V)하세요. 슬라이드 배경으로 사용하거나 카피 생성 시 참고 이미지로 활용됩니다.
최대 10장, 장당 원본 20MB까지 — 올리면 자동으로 압축해서 평균 100~300KB로 줄여줘요. 용량 걱정 없이 그냥 올리시면 됩니다.
이미지를 여기에 드래그하거나 클릭해서 선택 · 붙여넣기(Ctrl+V) 가능

카드뉴스 라이브러리

생성된 카드뉴스와 업로드 현황을 관리합니다.

DM 아웃리치 모니터링

어느 계정으로 누구에게 DM을 보냈고, 응답이 왔는지 추적합니다.

오픈채팅방 유입 허브

카카오톡 오픈채팅방은 앱 안에 직접 넣을 수 없어서, 링크·QR코드를 한곳에서 관리하는 용도예요. 카카오톡이 없으면 못 들어가니, 해외 인플루언서(트랙 B)에게는 인스타 DM/왓츠앱을 쓰는 게 낫습니다.
QR코드는 오프라인 전단지·포스터용으로 우클릭 저장해서 쓰시면 돼요.
유입 채널 체크리스트: 인스타·틱톡 프로필 링크 · DM 자동응답 · 당근·모델나라 게시글 · 오프라인 QR

계약·제휴 모니터링

광고주·인플루언서·에이전트와의 계약 진행 단계를 관리합니다.

계정 지수 조회

무료로 쓸 수 있는 기존 서비스에 바로 연결합니다. 자체 지수를 만들지 않고, 신뢰도 있는 외부 서비스를 그대로 활용해요.

Social Blade — 인스타그램·틱톡·유튜브·트위터

팔로워 추이, 참여율, 랭킹 등급을 무료로 볼 수 있어요. 아이디만 입력하면 바로 이동합니다.

HypeAuditor — 인스타그램 무료 간편 진단

팔로워 진위성(가짜 팔로워 비율)을 무료로 간단히 확인할 수 있어요. 사이트에서 아이디를 직접 입력해주세요.

블로그 지수 (일본·대만·홍콩)

참고: 네이버 블로그 지수를 확인해주던 '블덱스'는 네이버 API 접근이 막혀 2025년 12월 서비스가 종료되었습니다. 지금은 각 블로그 플랫폼 자체 통계(관리자 페이지 > 통계)를 확인하는 것이 가장 정확해요.
  • 아메바블로그: 블로그 관리 > 액세스 분석 (본인 블로그만 무료 열람)
  • Pixnet(대만): 블로그 후台 > 流量統計 (본인 블로그만 무료 열람)
  • 샤오홍슈(홍콩): 계정 후台 > 数据中心 (크리에이터 계정 전환 시 무료 열람)
